4.1
Comparison with a single matrix constraint
The six-mode example has cubic contact. In a single prefix unfolding with cap one, the same
elementary loading is normal in both matrix factors and has quadratic contact. For a prefix cap
two, the rank-one point has slack and has first-order contact. Thus none of the five individual prefix
constraints alone yields the cubic exponent. This establishes a difference from any one such matrix
envelope, not from all possible nonlinear matrix parameterizations or arbitrary collections of matrix
constraints.
