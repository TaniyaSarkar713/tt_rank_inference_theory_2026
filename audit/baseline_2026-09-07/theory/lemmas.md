# Technical lemmas

Complete proofs and equations are in paper/appendix.tex.

L1: Product structure at cap-one TT cuts, proved by recursive rank-one unfolding factorization.
L2: Local block component bound ||B_S|| <= (lambda+t)(t/lambda)^|S|.
L3: Exact elementary witness path distance and target change.
L4: KL(P_B0,P_B1)=n||B1-B0||²/(2 sigma²); two-point interval bound.
L5: For unit A, max(omega_0(t),min(eta,t)) <= omega_eta(t) <= min(t,eta+omega_0(t+eta)).
L6: OLS chi-square/F localization and moments through order max(J,2).
L7: HOSVD residual <= sqrt(J) times the error to any block-product tensor.
L8: Pilot degree-l loading projection is O((h/lambda)^(q-l)) for l<q, if all true lower degrees vanish.
L9: Product-chart degree-l perturbation <= sqrt(binomial(J,l)) rho^l/(shat-rho)^(l-1).
L10: Exact full-normal three-block coefficient is an injective norm.

The key statistical technical step is L8 combined with L6 on both the good and bad localization events. The structural step specific to capped TT classes is L3's feasibility under every internal cap.
